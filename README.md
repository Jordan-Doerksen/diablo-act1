# diablo-act1

game · arpg vertical slice

A single-file canvas ARPG — a winnable vertical slice from the Rogue Encampment
through the Blood Moor and Den of Evil to Blood Raven. Three playable classes,
D2-style safe-zone map generation, loot, enemy AI, and an act boss.

**No build tools. No frameworks.** Open `index.html`.

## What it is
One HTML file with a requestAnimationFrame game loop: combat, loot, procedural
zones with guaranteed safe spawns, three distinct class kits, and a victory screen.

## Run
```
start index.html
```

## Status
Playable slice, in development.
